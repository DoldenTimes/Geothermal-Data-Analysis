# README Contents

The file README.md should be ignored.

# FOLDER USAGE

Initial data should be taken from the Baseline folder. No edits should be made to the Baseline folder.
Data should be taken from provided downwell data and geometry. The provided model is purely for reference as to what the starting point of a calibration is, and should not be used as factual data.
Any scripts written should be stored in the Scripts folder.
Any data output files should be stored in the Output folder.

# Purpose of interpretation

All data should be interpreted in order to provide the most effective information for an engineer or another agent to calibrate a geothermal reservoir model.
Include the prompt and all steps taken in a seperate file in Output.

# Timeline

Analysis should be of the natural state of the system. Production and future states can be ignored for now.
